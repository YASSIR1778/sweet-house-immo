# دليل سويت هاوس للعقار — Sweet House Immobilier

هذا الدليل يشرح كل ما تحتاجه: ما الذي يحتويه النظام، كيف تجرّبه الآن، كيف يستعمله الفريق يومياً، وكيف تشغّله بقاعدة بيانات حقيقية وتنشره على الإنترنت.

---

## 1) ما الذي يحتويه النظام؟

النظام ثلاثة أجزاء في موقع واحد:

| الجزء | الرابط | لمن؟ |
|---|---|---|
| **الموقع العام** | `/` | الزبناء: البحث عن عقار، التفاصيل، طلب زيارة، عرض عقار للبيع |
| **لوحة القيادة** | `/admin` (بحساب المدير) | أنت: الأرقام، العمولات، الفريق، الإعدادات |
| **مكتب الكاتبة** | `/admin` (بحساب الكاتبة) | الكاتبة: المكالمات، المواعيد، الطلبات، العملاء، المهام |

### الموقع العام (3 لغات: العربية، الفرنسية، الإسبانية)
- صفحة رئيسية بصورة تطوان، بحث سريع (شراء / كراء، النوع، الحي، الميزانية) وأرقام الوكالة.
- قائمة العقارات بفلاتر كاملة وعرض على **الخريطة** بالأثمنة.
- صفحة لكل عقار: معرض صور، المواصفات، المزايا، الخريطة، فيديو يوتيوب، **حاسبة القرض**، زر واتساب برسالة جاهزة، طلب زيارة، وطباعة.
- صفحة «بيع أو كراء عقارك» لجلب عقارات جديدة من الملاك.
- المفضلة: الزائر يحفظ العقارات ويرسل قائمته للوكالة عبر واتساب.
- مهيّأ لمحركات البحث (Google) ولمعاينة الروابط في واتساب وفيسبوك.

### لوحة المدير
- **لوحة القيادة:** عقارات منشورة، طلبات الأسبوع، زيارات الأسبوع، عمولات الشهر، رسم بياني للعمولات، مسار الطلبات ونسبة النجاح، مصادر الزبناء، أداء الفريق، أكثر العقارات مشاهدة.
- **الصفقات والعمولات** (لا تراها الكاتبة)، **الفريق** (تفعيل الحسابات والأدوار)، **سجل النشاط** (من فعل ماذا ومتى)، **الإعدادات** (كل نصوص الموقع وصوره بدون برمجة).

### مكتب الكاتبة
- **مكتبي:** مواعيد اليوم (تم / لم يحضر / ورقة الزيارة / تذكير واتساب)، الطلبات الجديدة، مهامي، مكالمات اليوم، مواعيد الغد للتذكير، وبحث سريع عن عقار أثناء المكالمة لإرسال رابطه مباشرة.
- **تسجيل مكالمة** في ثوانٍ: يتعرف تلقائياً على العميل من رقمه، ويمكنه تحويل المكالمة إلى طلب وإضافة تذكير بمعاودة الاتصال.
- **الطلبات** على شكل لوحة: جديد ← تم الاتصال ← زيارة ← تفاوض ← ناجح / لم ينجح (اسحب البطاقة بين الأعمدة).
- **العملاء** مع **المطابقة التلقائية**: لكل عميل تظهر العقارات التي تناسب ميزانيته وطلبه، ويمكن إرسالها له عبر واتساب بلغته.
- **المواعيد** (أسبوع / قائمة) مع تنبيه عند تضارب المواعيد.
- **المهام** والتذكيرات، و**سجل المكالمات**.

### وثائق جاهزة للطباعة
- **بطاقة الواجهة (A4):** صور، ثمن، مواصفات و**رمز QR** يفتح صفحة العقار. من «العقارات ← ⋮ ← طباعة بطاقة الواجهة».
- **ورقة الزيارة (Bon de visite) بالعربية والفرنسية:** يوقّعها الزائر وتحمي عمولتك. من الموعد ← «ورقة الزيارة».

### الأدوار والصلاحيات
| | المدير | الكاتبة |
|---|:-:|:-:|
| العقارات: إضافة وتعديل ونشر | ✓ | ✓ |
| حذف عقار / عميل / طلب | ✓ | ✗ |
| الطلبات، العملاء، المواعيد، المهام، المكالمات | ✓ | ✓ |
| الصفقات والعمولات | ✓ | ✗ |
| الفريق، سجل النشاط، الإعدادات | ✓ | ✗ |
| الملاحظات الخاصة بالعقار (أقل ثمن، المفتاح…) | ✓ | ✓ — ولا تظهر أبداً في الموقع |

## 2) التجربة الآن (الوضع التجريبي)

بدون أي إعداد، يعمل النظام في **وضع تجريبي** ببيانات نموذجية (18 عقاراً، عملاء، طلبات، مواعيد…) محفوظة في المتصفح فقط.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5174/sweet-house-immo/` للموقع، و`/sweet-house-immo/admin` للوحة واختر **«الدخول كمدير»** أو **«الدخول ككاتبة»**.

> للعودة إلى البيانات النموذجية: الإعدادات ← البيانات والنسخ ← «إعادة البيانات التجريبية».

## 3) التشغيل الحقيقي بقاعدة بيانات (Supabase — مجاني)

### أ. إنشاء المشروع
1. ادخل إلى **supabase.com** بحسابك ← **New project**.
2. الاسم: `sweet-house-immo` — المنطقة: **Europe (Frankfurt أو Paris)** — اختر كلمة مرور قوية للقاعدة واحفظها.

> الأفضل مشروع مستقل عن مشروع المكتبة. إن اضطررت لاستعمال نفس المشروع فلا مشكلة: كل الجداول تبدأ بـ `re_` ولا تلمس جداول المكتبة.

### ب. إنشاء الجداول
1. افتح الملف `supabase/schema.sql`.
2. في السطر الذي فيه `OWNER_EMAIL@example.com` **اكتب بريدك الإلكتروني** (هذا البريد سيصبح حساب المدير).
3. في Supabase: **SQL Editor ← New query** ← الصق الملف كاملاً ← **Run**.

### ج. إعدادات الدخول
في **Authentication ← URL Configuration**:
- **Site URL:** `https://yassir1778.github.io/sweet-house-immo/admin`
- **Redirect URLs:** أضف `https://yassir1778.github.io/sweet-house-immo/admin/reset` و `http://localhost:5174/sweet-house-immo/admin/reset`

### د. ربط الموقع بالقاعدة
1. في Supabase: **Project Settings ← API** انسخ **Project URL** و**Publishable key** (أو anon key).
   > هذان المفتاحان عموميان وآمنان (الحماية مضمونة بقواعد الصلاحيات في القاعدة). **لا تنسخ أبداً مفتاح service_role أو secret.**
2. في GitHub: المستودع ← **Settings ← Secrets and variables ← Actions ← Variables** ← أضف:
   - `VITE_SUPABASE_URL` = رابط المشروع
   - `VITE_SUPABASE_ANON_KEY` = المفتاح العمومي
3. للتجربة على جهازك: انسخ `.env.example` إلى `.env.local` واملأ نفس القيمتين.

### هـ. إنشاء الحسابات
1. افتح `/admin` ← **«عضو جديد؟ أنشئ حساباً»** ← سجّل **ببريدك المكتوب في الملف** ← يصبح حسابك **مديراً** مباشرة.
2. الكاتبة تفعل نفس الشيء ببريدها ← يظهر حسابها عندك في **الفريق** ← اضغط **«تفعيل الآن»**.
3. (اختياري) بعد إنشاء كل الحسابات: **Authentication ← Sign In / Providers ← Allow new users to sign up = Off**.

> إن كان Supabase يطلب تأكيد البريد الإلكتروني، افتح الرسالة واضغط الرابط قبل الدخول.

## 4) النشر على الإنترنت (GitHub Pages — مجاني)

1. أنشئ مستودعاً باسم `sweet-house-immo` في حسابك على GitHub وارفع هذا المجلد.
2. **Settings ← Pages ← Source = GitHub Actions**.
3. كل تعديل يُرفع إلى الفرع `main` يُنشر تلقائياً على: `https://yassir1778.github.io/sweet-house-immo/`

### نطاق خاص لاحقاً (مثلاً immo.sweethouse.ma)
- غيّر `VITE_BASE` إلى `/` في ملف `.github/workflows/deploy.yml`، وأضف النطاق في **Settings ← Pages ← Custom domain**، ثم حدّث روابط Supabase (الخطوة ج).
- غيّر `SITE_ORIGIN` في `src/shared/lib/config.ts` إلى النطاق الجديد.

## 5) الاستعمال اليومي (نصائح سريعة)

**الكاتبة — كل صباح:**
1. افتحي **مكتبي**: راجعي مواعيد اليوم والطلبات الجديدة (الأحمر = أكثر من 24 ساعة بدون رد).
2. أي مكالمة ← زر **«تسجيل مكالمة»** (الأعلى) — 20 ثانية تكفي.
3. قبل كل زيارة ← **ورقة الزيارة** للطباعة، وبعدها ← **«تم»** أو **«لم يحضر»**.
4. آخر النهار ← **مواعيد الغد** ← أرسلي التذكيرات عبر واتساب بضغطة.

**المدير — كل أسبوع:**
1. **لوحة القيادة:** الطلبات، الزيارات، العمولات، أداء الفريق.
2. **الطلبات:** ما هي العالقة في «تفاوض»؟
3. **الإعدادات ← البيانات:** نزّل **نسخة احتياطية** واحفظها في Google Drive.

**عند إضافة عقار:**
- 8 صور على الأقل، الأولى هي الغلاف (اسحب الصور لترتيبها).
- ضع الدبوس على الخريطة (أو «مركز الحي» إن كنت لا تريد إظهار المكان الدقيق).
- اكتب في **الملاحظات الخاصة** أقل ثمن والعمولة ومكان المفتاح — لا تظهر أبداً للزبناء.
- الترجمة الفرنسية/الإسبانية تجلب المغاربة المقيمين بالخارج والإسبان.

## 6) أسئلة متكررة

**هل يرى الزبناء ملاحظاتي الخاصة أو بيانات المالك؟** لا. الموقع يقرأ من نافذة خاصة في القاعدة لا تحتوي هذه الحقول.

**هل تستطيع الكاتبة رؤية العمولات؟** لا. الصفقات والعمولات وسجل النشاط والإعدادات للمدير فقط، والقاعدة نفسها ترفض ذلك حتى لو حاولت.

**كيف أغيّر رقم الهاتف أو صورة الغلاف أو النصوص؟** الإعدادات ← الوكالة / الصفحة الرئيسية ← حفظ. يظهر التغيير فوراً.

**كيف أضيف حياً جديداً؟** الإعدادات ← المناطق والمراجع ← «منطقة جديدة».

**ورقة الزيارة قانونية؟** النص قابل للتعديل من الإعدادات ← الوثائق. اعرضه على موثق أو محامٍ قبل اعتماده.
