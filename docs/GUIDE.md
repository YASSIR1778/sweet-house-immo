# دليل سويت هاوس للعقار — Sweet House Immobilier

هذا الدليل يشرح كل ما تحتاجه: ما الذي يحتويه النظام، كيف تجرّبه الآن، كيف يستعمله الفريق يومياً، وكيف تشغّله بقاعدة بيانات حقيقية وتنشره على الإنترنت.

---

## 1) ما الذي يحتويه النظام؟

النظام ثلاثة أجزاء في موقع واحد:

| الجزء | الرابط | لمن؟ |
|---|---|---|
| **الموقع العام** | `/` | الزبناء: البحث عن عقار، التفاصيل، طلب زيارة، عرض عقار للبيع |
| **لوحة القيادة** | `/admin` (بحساب المدير) | أنت: الأرقام، العمولات، الفريق، الإعدادات |
| **مكتب الكاتبة** | `/admin` (بحساب الكاتبة) | الكاتبة: المكالمات، المواعيد، الطلبات، العملاء، المهام |

### الموقع العام (3 لغات: العربية، الفرنسية، الإسبانية)
- صفحة رئيسية بصورة تطوان، بحث سريع (شراء / كراء، النوع، الحي، الميزانية) وأرقام الوكالة.
- قائمة العقارات بفلاتر كاملة وعرض على **الخريطة** بالأثمنة.
- صفحة لكل عقار: معرض صور، المواصفات، المزايا، الخريطة، فيديو يوتيوب، **حاسبة القرض**، زر واتساب برسالة جاهزة، طلب زيارة، وطباعة.
- صفحة «بيع أو كراء عقارك» لجلب عقارات جديدة من الملاك.
- المفضلة: الزائر يحفظ العقارات ويرسل قائمته للوكالة عبر واتساب.
- مهيّأ لمحركات البحث (Google) ولمعاينة الروابط في واتساب وفيسبوك.

### لوحة المدير
- **لوحة القيادة:** عقارات منشورة، طلبات الأسبوع، زيارات الأسبوع، عمولات الشهر، رسم بياني للعمولات، مسار الطلبات ونسبة النجاح، مصادر الزبناء، أداء الفريق، أكثر العقارات مشاهدة.
- **الصفقات والعمولات**، **الفريق** (إضافة الموظفين، كلمات مرورهم وصلاحياتهم)، **سجل النشاط** (من فعل ماذا ومتى)، **الإعدادات** (كل نصوص الموقع وصوره بدون برمجة).

### مكتب الكاتبة
- **مكتبي:** مواعيد اليوم (تم / لم يحضر / ورقة الزيارة / تذكير واتساب)، الطلبات الجديدة، مهامي، مكالمات اليوم، مواعيد الغد للتذكير، وبحث سريع عن عقار أثناء المكالمة لإرسال رابطه مباشرة.
- **تسجيل مكالمة** في ثوانٍ: يتعرف تلقائياً على العميل من رقمه، ويمكنه تحويل المكالمة إلى طلب وإضافة تذكير بمعاودة الاتصال.
- **الطلبات** على شكل لوحة: جديد ← تم الاتصال ← زيارة ← تفاوض ← ناجح / لم ينجح (اسحب البطاقة بين الأعمدة).
- **العملاء** مع **المطابقة التلقائية**: لكل عميل تظهر العقارات التي تناسب ميزانيته وطلبه، ويمكن إرسالها له عبر واتساب بلغته.
- **المواعيد** (أسبوع / قائمة) مع تنبيه عند تضارب المواعيد.
- **المهام** والتذكيرات، و**سجل المكالمات**.

### وثائق جاهزة للطباعة
- **بطاقة الواجهة (A4):** صور، ثمن، مواصفات و**رمز QR** يفتح صفحة العقار. من «العقارات ← ⋮ ← طباعة بطاقة الواجهة».
- **ورقة الزيارة (Bon de visite) بالعربية والفرنسية:** يوقّعها الزائر وتحمي عمولتك. من الموعد ← «ورقة الزيارة».

### الأدوار والصلاحيات
- **المدير:** كل الصلاحيات، ويضيف الموظفين ويغيّر كلمات مرورهم وصلاحياتهم.
- **الموظف** (كاتبة، وكيل عقاري…): يشتغل دائماً على الطلبات، العملاء، المواعيد، المهام، المكالمات، ويرى العقارات. وأنت تختار له من صفحة **الفريق** ما يُسمح له به زيادة على ذلك:

| الصلاحية | ماذا تفتح | عند موظف جديد |
|---|---|:-:|
| إضافة وتعديل العقارات | إنشاء العقارات، تعديلها، نشرها ورفع صورها | ✓ |
| الحذف | حذف العقارات والعملاء والطلبات | ✗ |
| الصفقات والعمولات | رؤية الصفقات والعمولات وتسجيلها | ✗ |
| لوحة القيادة | الأرقام والإحصائيات العامة للوكالة | ✗ |
| تصدير البيانات | تحميل القوائم كملفات Excel والنسخة الاحتياطية | ✗ |
| إعدادات الموقع | نصوص الموقع وصوره، الأحياء ومعلومات الوكالة | ✗ |
| سجل النشاط | من قام بماذا ومتى | ✗ |

القاعدة نفسها تطبّق هذه الصلاحيات: من لا يملك صلاحية لا يستطيع تنفيذها حتى لو حاول من خارج اللوحة. حساب صاحب الوكالة يبقى دائماً مديراً مفعّلاً، ولا يستطيع أحد إيقافه.
الملاحظات الخاصة بالعقار (أقل ثمن، المفتاح…) يراها الفريق فقط، ولا تظهر أبداً في الموقع.

## 2) التجربة الآن (الوضع التجريبي)

بدون أي إعداد، يعمل النظام في **وضع تجريبي** ببيانات نموذجية (18 عقاراً، عملاء، طلبات، مواعيد…) محفوظة في المتصفح فقط.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5174/sweet-house-immo/` للموقع، و`/sweet-house-immo/admin` للوحة واختر **«الدخول كمدير»** أو **«الدخول ككاتبة»**.

> للعودة إلى البيانات النموذجية: الإعدادات ← البيانات والنسخ ← «إعادة البيانات التجريبية».

## 3) التشغيل الحقيقي بقاعدة بيانات (Supabase — مجاني)

الوكالة لها **حساب Supabase خاص بها**، منفصل تماماً عن حساب المكتبة: الخطة المجانية لا تسمح إلا بمشروعين لكل شخص، والفصل يمنع أي خلط بين النشاطين.

### أ. إنشاء الحساب والمشروع (تفعلها أنت)
1. ادخل إلى **supabase.com/dashboard/sign-up** وسجّل **ببريد الوكالة وكلمة مرور**، وليس بزر GitHub (زر GitHub يُدخلك إلى حساب المكتبة).
2. افتح رسالة التأكيد في بريدك واضغط الرابط.
3. أنشئ **Organization** بالخطة **Free**، ثم **New project**:
   - الاسم: `sweet-house-immo`
   - **Database password:** اضغط «Generate» واحفظها في مكان آمن (لن تحتاجها يومياً).
   - المنطقة: **Europe — Frankfurt (eu-central-1)**.
4. انتظر دقيقتين حتى يصبح المشروع جاهزاً.

### ب. إنشاء الجداول
1. افتح الملف `supabase/schema.sql`، وفي السطر الذي فيه `OWNER_EMAIL@example.com` اكتب **البريد الذي ستدخل به لوحة الوكالة**: هذا الحساب يصبح مديراً تلقائياً.
2. في Supabase: **SQL Editor ← New query** ← الصق الملف كاملاً ← **Run**. يجب أن تظهر «Success».

### ج. إعدادات الدخول
في **Authentication ← URL Configuration**:
- **Site URL:** `https://yassir1778.github.io/sweet-house-immo/admin`
- **Redirect URLs:** أضف `https://yassir1778.github.io/sweet-house-immo/**`

### د. ربط الموقع بالقاعدة
1. في Supabase: زر **Connect** أعلى الصفحة، أو **Project Settings ← API Keys**: انسخ **Project URL** و**Publishable key** (يبدأ بـ `sb_publishable_`).
   > هذان عموميان وآمنان: الحماية مضمونة بقواعد الصلاحيات داخل القاعدة. **لا تشارك أبداً مفتاح `secret` أو `service_role` ولا كلمة مرور القاعدة.**
2. أضفهما في GitHub: المستودع ← **Settings ← Secrets and variables ← Actions ← Variables**:
   - `VITE_SUPABASE_URL` = رابط المشروع
   - `VITE_SUPABASE_ANON_KEY` = المفتاح العمومي
3. أعد النشر: **Actions ← Deploy to GitHub Pages ← Run workflow**. بعد دقيقتين يعمل الموقع بالقاعدة الحقيقية.
4. للتجربة على جهازك: انسخ `.env.example` إلى `.env.local` واملأ نفس القيمتين.

### هـ. إنشاء الحسابات
1. **حسابك أنت:** سجّل في `/admin` **بالبريد المكتوب في الملف** (أو أنشئه من **Authentication ← Users ← Add user** مع **Auto Confirm User**): تصبح **المدير** تلقائياً.
2. **خدمة حسابات الفريق (مرة واحدة):** في Supabase ← **Edge Functions ← Deploy a new function ← Via Editor**، الاسم `re-staff`، والصق محتوى الملف `supabase/functions/re-staff/index.ts` ثم **Deploy**. المفتاح السري يصلها تلقائياً من Supabase ولا يظهر في الموقع أبداً.
3. **إضافة موظف:** **الفريق ← إضافة موظف** ← الاسم، الوظيفة، البريد، الهاتف، **كلمة المرور** (أو «اقترح كلمة»)، نوع الحساب والصلاحيات ← **إضافة الموظف** ← **نسخ بيانات الدخول** وأرسلها له. الحساب جاهز ومفعّل فوراً، ولا يحتاج تأكيد البريد.
4. **نسي كلمة مروره؟** **الفريق ← كلمة المرور** على بطاقته ← كلمة جديدة ← حفظ ← أعطه إياها.
5. **تغيير كلمة المرور بنفسه:** كل عضو يغيّر كلمة مروره من **زر المفتاح** أسفل القائمة بجانب زر الخروج.
6. **تعديل، إيقاف، حذف:** زر **تعديل** على بطاقة العضو: الاسم، البريد، الصلاحيات، إيقاف الحساب مؤقتاً، أو **حذف الحساب** نهائياً.
7. (اختياري) بعد ذلك: **Authentication ← Sign In / Providers ← Allow new users to sign up = Off**، حتى لا يُنشأ أي حساب إلا من صفحة «الفريق».

### و. الظهور في Google
الموقع الحقيقي **لا يظهر في Google** حتى تقرر ذلك، حتى تضيف عقاراتك الحقيقية وتصحح معلومات الوكالة أولاً. عندما تكون جاهزاً: أضف في متغيرات GitHub `VITE_ALLOW_INDEXING` = `true` ثم أعد النشر.

## 4) النشر على الإنترنت (GitHub Pages — مجاني)

- المستودع: `github.com/YASSIR1778/sweet-house-immo`، والموقع: `https://yassir1778.github.io/sweet-house-immo/`
- كل تعديل يُرفع إلى الفرع `main` يُنشر تلقائياً خلال دقيقتين تقريباً (**Actions** تعرض حالة النشر).

### نطاق خاص لاحقاً (مثلاً immo.sweethouse.ma)
- غيّر `VITE_BASE` إلى `/` في ملف `.github/workflows/deploy.yml`، وأضف النطاق في **Settings ← Pages ← Custom domain**، ثم حدّث روابط Supabase (الخطوة ج).
- غيّر `SITE_ORIGIN` في `src/shared/lib/config.ts` إلى النطاق الجديد.

## 5) الاستعمال اليومي (نصائح سريعة)

**الكاتبة — كل صباح:**
1. افتحي **مكتبي**: راجعي مواعيد اليوم والطلبات الجديدة (الأحمر = أكثر من 24 ساعة بدون رد).
2. أي مكالمة ← زر **«تسجيل مكالمة»** (الأعلى) — 20 ثانية تكفي.
3. قبل كل زيارة ← **ورقة الزيارة** للطباعة، وبعدها ← **«تم»** أو **«لم يحضر»**.
4. آخر النهار ← **مواعيد الغد** ← أرسلي التذكيرات عبر واتساب بضغطة.

**المدير — كل أسبوع:**
1. **لوحة القيادة:** الطلبات، الزيارات، العمولات، أداء الفريق.
2. **الطلبات:** ما هي العالقة في «تفاوض»؟
3. **الإعدادات ← البيانات:** نزّل **نسخة احتياطية** واحفظها في Google Drive.

**عند إضافة عقار:**
- 8 صور على الأقل، الأولى هي الغلاف (اسحب الصور لترتيبها).
- ضع الدبوس على الخريطة (أو «مركز الحي» إن كنت لا تريد إظهار المكان الدقيق).
- اكتب في **الملاحظات الخاصة** أقل ثمن والعمولة ومكان المفتاح — لا تظهر أبداً للزبناء.
- الترجمة الفرنسية/الإسبانية تجلب المغاربة المقيمين بالخارج والإسبان.

## 6) أسئلة متكررة

**هل يرى الزبناء ملاحظاتي الخاصة أو بيانات المالك؟** لا. الموقع يقرأ من نافذة خاصة في القاعدة لا تحتوي هذه الحقول.

**هل تستطيع الكاتبة رؤية العمولات؟** لا، إلا إذا منحتها صلاحية «الصفقات والعمولات» من **الفريق**. القاعدة نفسها ترفض أي عملية بدون صلاحيتها.

**نسيت الكاتبة كلمة مرورها؟** **الفريق ← كلمة المرور** على بطاقتها، اكتب كلمة جديدة وأعطها إياها. لا تحتاج أي رسالة بريد.

**كيف أغيّر رقم الهاتف أو صورة الغلاف أو النصوص؟** الإعدادات ← الوكالة / الصفحة الرئيسية ← حفظ. يظهر التغيير فوراً.

**كيف أضيف حياً جديداً؟** الإعدادات ← المناطق والمراجع ← «منطقة جديدة».

**ورقة الزيارة قانونية؟** النص قابل للتعديل من الإعدادات ← الوثائق. اعرضه على موثق أو محامٍ قبل اعتماده.
